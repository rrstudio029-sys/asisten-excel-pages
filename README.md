# Asisten Excel — public listing pages


Static website files for the Asisten Excel plugin by Shafira Dev.


## Files
- `index.html` — product page
- `privacy.html` — privacy policy
- `terms.html` — terms of use
- `support.html` — support page
- `assets/icon-256.png` — listing icon (256×256)


## Publish free with GitHub Pages
1. Create a **public** GitHub repository, e.g. `asisten-excel-pages`.
2. Upload all files and folders in this package to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish. The public URLs will be:
   - `https://rrstudio029-sys.github.io/asisten-excel-pages/`
   - `https://rrstudio029-sys.github.io/asisten-excel-pages/privacy.html`
   - `https://rrstudio029-sys.github.io/asisten-excel-pages/terms.html`
   - `https://rrstudio029-sys.github.io/asisten-excel-pages/support.html`


## Before public plugin submission
- Use the published URLs above in the submission listing.
- Confirm the publisher identity **Shafira Dev** in the publishing portal.
- Confirm country availability and complete the portal's required policy attestations.
- The pages describe the current skill-only plugin. If the plugin later gains a backend, data collection, analytics, or external integrations, update the privacy policy before release.


This package does not itself publish the plugin or change its PRIVATE visibility.
