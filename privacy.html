Kebijakan Privasi

Berlaku mulai: 6 November 2026

Kebijakan ini menjelaskan praktik privasi plugin Asisten Excel yang diterbitkan oleh Shafira Dev.

Data yang dikumpulkan oleh plugin

Asisten Excel merupakan plugin berbasis instruksi (skill) di ChatGPT. Plugin ini tidak menyediakan server backend, akun pengguna, formulir pendaftaran, analitik pihak ketiga, atau basis data milik plugin. Plugin tidak secara mandiri mengumpulkan, menyimpan, atau menjual data pengguna.

Konten percakapan dan file

Jika Anda memasukkan teks, mengunggah workbook, atau memberikan data spreadsheet dalam percakapan, konten tersebut diproses oleh ChatGPT sesuai pengaturan, kebijakan privasi, dan ketentuan OpenAI yang berlaku. Jangan masukkan kata sandi, kredensial, atau data pribadi yang tidak diperlukan. Plugin hanya dapat membantu menganalisis file yang benar-benar tersedia dalam percakapan dan melalui kemampuan ChatGPT yang tersedia.

Pihak ketiga

Plugin ini tidak mengintegrasikan layanan eksternal atau mengirim data langsung ke Microsoft, penyedia penyimpanan cloud, maupun layanan analitik. Penggunaan ChatGPT tetap tunduk pada kebijakan OpenAI.

Retensi dan keamanan

Karena plugin tidak mengoperasikan penyimpanan atau server sendiri, plugin tidak memiliki jadwal retensi data pengguna yang terpisah. Pengelolaan percakapan dan file mengikuti kontrol serta kebijakan platform ChatGPT. Hindari mengunggah informasi rahasia atau sensitif.

Perubahan kebijakan

Kebijakan ini dapat diperbarui jika fungsi plugin berubah. Versi terbaru akan dipublikasikan pada halaman ini.
